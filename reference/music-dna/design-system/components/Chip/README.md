# Chip

A small toggle for picking feelings, musical qualities, collections and filters.

- Shape carries meaning: round (`radius-pill`) for feelings and tabs, square (`radius-sm`) for musical qualities and quick answers.
- Sizes: 28px in strips and the ask row (12px text), 32px default (13px), 36px tabs (14px).
- Off: transparent, `line-strong` border, #b4b4b9 text. On: `chip-on` fill, `chip-on-line` border, `ink` text. Use `aria-pressed` for toggles, `aria-selected` for tabs.
- Never fill a chip solid white or accent: the accent is reserved for chosen moments.
