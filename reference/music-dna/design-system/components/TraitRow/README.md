# TraitRow

One learned trait as an open list row: how strong it is, its best example to play, and a quick way to confirm or correct it.

- Three aligned columns (`minmax(0,1fr) 240–280px 230–250px`): strength meter + name + one-line meaning and count · round play button + best moment and what the analysis heard · "Strong match" or "Is this you? Yes / Not really". One column on phones.
- Meter: four rising bars, filled with `accent` by level (Emerging 1, Growing 2–3, Strong 4).
- Rows are separated by `line` hairlines only. No cards, no boxes.
- Tapping the name opens the moments behind the trait directly under the row (indented 32px): the genres it spans, each moment with play / range / Remove, and "Find unfamiliar moments like these →".
- The open row's name turns `accent` and its arc lights up in the TraitRing.
